Pahana Edu Bookshop Management System

Pahana Edu is a leading bookshop in Colombo City, serving hundreds of customers each month.  
Currently, customer account details are maintained manually, which is inefficient and prone to errors.  
This project provides a **computerized online (web-based) system** to manage customer billing and account information efficiently.

Features
User Authentication (Login) 
  Secure access with username and password.
  Customer Management  
  - Register new customers with unique account numbers.  
  - Store details such as account number, name, address, telephone number, and units consumed.  
  - Edit/update existing customer details.  
Item Management 
  Add, update, and delete bookshop items.

- Billing System  
  - Compute the bill amount based on the number of units consumed.  
  - Generate and print bills for customers.  

- Account Information  
  Retrieve and display detailed customer account information.

- Help Section  
  Provides user-friendly guidelines and instructions for new users.

- Exit System 
  Securely close the application.

---

 🛠️ Technologies Used

- Programming Language: Java (JDK 17+)  
- Database: MySQL (for persistent storage) / Text files (alternative)  
- Tools & IDEs:** Apache NetBeans, IntelliJ IDEA, or Eclipse  
- **Application Type:** Menu-driven, console-based / web-based system
